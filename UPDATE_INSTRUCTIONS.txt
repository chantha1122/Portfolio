Required database update
------------------------
This version adds/updates Prisma models, including Comment and Like.
Keep your existing .env file and make sure PostgreSQL/Docker is running.

From the project root run:

npx prisma migrate dev
npx prisma generate

Then clear Next.js cache on Windows CMD:

rmdir /s /q .next

Then type-check:

npx tsc --noEmit

Then start:

npm run dev

Important
---------
- Keep your existing .env file. It is intentionally NOT included in the clean updated ZIP.
- Your existing database data is preserved by Prisma migrations.
- The generated Prisma client must be regenerated after copying this update because Comment/Like are new models.
- Public comments are NOT visible immediately. They are saved as pending and must be approved in Dashboard -> Comments.
- Likes use an anonymous browser visitor key stored in localStorage to avoid duplicate likes from the same browser for the same item.
- For Profile Image / Badge Image / CV, use a public path such as:
  /images/profile-badge.png
  /images/me.jpg
  /files/chantha-cv.pdf
  or a full public URL.
- The default badge image can be replaced later by setting Badge Image in Profile Management.
